FANATIK99 — WEBSITE STATIS

File:
- index.html: halaman utama responsif dengan SEO dasar
- robots.txt: aturan crawl dan lokasi sitemap
- sitemap.xml: sitemap untuk domain Vercel

CARA DEPLOY:
1. Ekstrak ZIP.
2. Unggah isi folder ini (bukan folder pembungkusnya) ke root repository GitHub yang terhubung ke Vercel.
3. Commit/push perubahan dan tunggu deployment Vercel berstatus Ready.
4. Pastikan https://fanatik99.vercel.app/ dan https://fanatik99.vercel.app/sitemap.xml dapat dibuka.
5. Di Google Search Console, periksa URL domain Vercel yang benar dan kirim sitemap.xml jika belum terkirim.

PENTING:
- Canonical diset ke https://fanatik99.vercel.app/.
- Tautan eksternal ditampilkan secara transparan. Jangan gunakan halaman ini untuk menyamarkan tujuan tautan atau mengelabui kebijakan platform.
- SEO tidak menjamin halaman akan diindeks Google.
- Sesuaikan isi dengan layanan yang benar-benar ada; jangan menambahkan klaim yang tidak bisa dibuktikan.
