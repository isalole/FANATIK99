PENTING SEBELUM DEPLOY:
1. Pertahankan domain fanatik99.vercel.app sebagai domain utama untuk versi ini.
2. Jangan memasang canonical ke fantik99.com atau fanatik99.my.id.
3. Pastikan deployment mengembalikan HTTP 200 untuk halaman utama, robots.txt, dan sitemap.xml.
4. Pastikan tidak ada redirect loop dan tidak ada aturan noindex di konfigurasi hosting.
5. Setelah deploy, buka https://fanatik99.vercel.app/robots.txt dan https://fanatik99.vercel.app/sitemap.xml untuk memastikan keduanya bisa diakses.
6. Di Google Search Console, lakukan Test Live URL. Jika berhasil, minta pengindeksan ulang untuk URL utama dan kirim sitemap.
